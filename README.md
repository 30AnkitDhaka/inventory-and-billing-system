# Business Management App

A web-based business management application designed to simplify day-to-day business operations. It provides a centralized platform for managing inventory, customer records, products, billing, and invoice generation.

## Features

- **Customer Management** – Maintain customer records and their details.
- **Inventory Management** – Manage products and keep track of stock availability.
- **Product Management** – Store and organize product information.
- **Invoice Generation** – Create invoices for customer purchases.
- **Dynamic Invoice Items** – Add multiple items to an invoice with adjustable quantities.
- **Automatic Total Calculation** – Calculate invoice totals based on items, quantities, and prices.
- **Database Integration** – Store and manage customer, product, inventory, and invoice records.

## Tech Stack

- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL
- **Frontend:** HTML, CSS, JavaScript
- **Tools:** IntelliJ IDEA, Git, GitHub

## Project Objective

The objective of this project is to develop a web-based solution that simplifies business operations by integrating inventory management, customer management, and billing into a single application.
